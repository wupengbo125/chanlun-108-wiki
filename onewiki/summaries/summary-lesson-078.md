# 第78课：继续说线段的划分

> 源文件：[[../../raw/078-教你炒股票78_继续说线段的划分.md|查看原文]]

## 基本概念
- 线段与笔都有方向：向上笔开始的线段必结束于向上笔，不能底到底、顶到顶；同一线段顶必高于底。
- 除最初一段外，每段都破坏前段；**破坏可逆时间传递**——被后段破坏的线段必破坏其前段。
- 从近期最高/最低点开始；熟练可直接分段，不熟则依次找分型、笔、线段。

## 古怪线段
- **古怪线段唯一成因**：第一种情况的笔破坏后，最终没有在该方向由该笔发展成线段破坏。
- 案例（线段B向下）：向上破坏笔未形成特征序列分型，则该方向破坏不了；随后向下线段若破该笔底则B延续，没破则向上笔可延伸出线段、B被破坏。
- 第二种情况中，若 C 未形成第二特征序列分型就直接新高/新低，不能算三段，只能并为一段。
- **第二种情况的第二特征序列分型必须严格按包含关系处理**（与第一种分界点两边不可包含相反）：包含意味着原线段能量充足，而第二种本就转折能量不足。

## 线段标准化
- 若最高/最低点不是线段端点，在以线段为基础部件的分析中可标准化为高低点都在端点（只关心实际区间）。
- 标准化后线段首尾相连成连续折线，为中枢、走势类型分析提供标准基础部件。
