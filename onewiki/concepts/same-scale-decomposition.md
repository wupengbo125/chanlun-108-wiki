# 走势类型连接的同级别分解

> **关联原文**：[[../../raw/038-教你炒股票38_走势类型连接的同级别分解.md|教你炒股票38课]]、[[../../raw/039-教你炒股票39_同级别分解再研究.md|教你炒股票39课]]、[[../../raw/040-教你炒股票40_同级别分解的多重赋格.md|教你炒股票40课]]

## 概述

**同级别分解**是缠论处理实盘分析多义性的利刃。它将原本因中枢扩展/扩张导致级别不断变动的复杂系统，固定在某一个选定级别（如 30 分钟）上，将其视作一系列彼此独立的同级别上涨、下跌与盘整走势类型的首尾相连。

## 同级别分解的核心原则

1. **固定视角，拒绝级别混乱**：选定操作级别后，所有走势均分解为该级别的标准段，不再随意调整级别。
2. **首尾相连无间断**：任何走势都表达为：$A_1 + A_2 + A_3 + \dots + A_n$，其中每个 $A_i$ 均为已完成的同级别走势类型。
3. **同级别买卖点判定**：
   - 向上走势类型结束的极值点即为同级别第一类卖点；
   - 向下走势类型结束的极值点即为同级别第一类买点。

## 实战优势
- **操作标准化**：彻底规避了因中枢升级造成的“级别恐慌”；
- **机械化执行**：在固定级别上不断通过一买进、一卖出，实现精准的波段差价与滚动复利。
