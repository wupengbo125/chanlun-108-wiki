# 区间套定位定理与精确打击

> **关联原文**：[[../../raw/061-教你炒股票61_区间套定位标准图解_分析示范六_.md|教你炒股票61课]]、[[../../raw/070-教你炒股票70_一个教科书式走势的示范分析.md|教你炒股票70课]]

## 概述

**区间套定理**是缠论技术分析中最具杀伤力的数学显微镜。它利用走势自相似性，在不同时间周期上像套娃一样层层放大背驰段，使得在年线或日线级别发现的买卖点，能够精确锁定在 1 分钟甚至分时图的极值拐点。

```mermaid
    B --> C[锁定 30分钟离开段 [t1, t2]]
    C --> D[切换到 5分钟级别观察内部背驰]
    D --> E[切换到 1分钟级别寻找终极第一类买卖点]
    E --> F[精确打击: 买在最低点, 卖在最高点]
```

## 区间套操作四步法

1. **第一步（大级别锁定）**：在日线（或30分钟）图上观察到趋势走势出现背驰迹象，锁定当前正在走出的离开段时间区间；
2. **第二步（次级别定位）**：切换到次级别（如30分钟或5分钟），观察该离开段内部是否形成次级别的中枢与离开段；
3. **第三步（微观级别递归）**：继续下潜到 1 分钟级别，观察其内部背驰是否完成；
4. **第四步（针尖出击）**：当 1 分钟级别完成底分型与第一类买点的一瞬间，果断全仓接入，完成对大级别拐点的精确狙击。
