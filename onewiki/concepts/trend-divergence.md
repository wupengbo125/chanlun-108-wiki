# 趋势背驰与标准背驰判定

> **关联原文**：[[../../raw/015-教你炒股票15_没有趋势_没有背驰.md|教你炒股票15课]]、[[../../raw/024-教你炒股票24_MACD对背弛的辅助判断.md|教你炒股票24课]]、[[../../raw/029-教你炒股票29_转折的力度与级别.md|教你炒股票29课]]、[[../../raw/037-教你炒股票37_背驰的再分辨.md|教你炒股票37课]]

## 概述

**背驰**（Divergence）是缠论动力学的灵魂。背驰揭示了价格创新高（或新低）时，内在推动力量（资金动能、量能、指标动量）不增反减的物理衰竭过程。“没有趋势，没有背驰”，标准背驰必然发生在包含两个以上中枢的趋势走势中。

```mermaid
graph LR
    A[进入段 a] --> B[第一中枢 A]
    B --> C[连接段 b]
    C --> D[第二中枢 B]
    D --> E[离开段 c: 创新高/低]
    E -.->|动能对比: c < b 或 c < a| F[触发背驰: 产生第一类买卖点]
```

## 标准趋势背驰的数学判定

设一个标准上涨趋势为 $a + A + b + B + c$：
- $A, B$ 为同级别走势中枢，且 $ZD_B > ZG_A$；
- $c$ 段为创新高的离开段；
- **背驰判定法则**：比较 $c$ 段与 $b$ 段（或 $c$ 段与 $a+b$ 段）的动能。若 $c$ 段创出新高，但其内部动能指标（如 MACD 面积或黄白线高度）显著小于 $b$ 段，则判定为**趋势背驰**。

## 背驰转折的三种后果
趋势背驰确立后，必然导致以下三种演化之一：
1. 产生反向走势类型的转折（如上涨转为下跌）；
2. 形成更大级别的走势中枢（围绕最后一个中枢扩展）；
3. 形成同级别的大级别盘整。
