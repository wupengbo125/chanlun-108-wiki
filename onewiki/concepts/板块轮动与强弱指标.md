# 板块轮动与缠中说禅板块强弱指标

## 级别与均线对应
- 任一级别都有最少延伸时间（如一笔至少延伸6个基本 K 线单位、须能碰到5日线），并对应最少挑战的均线。
- 走势级别与均线无必然关系，但有大致区间对应；一个趋势中各中枢对应的压制均线大致相同（第一中枢被某均线压制，后继中枢很可能被同样均线压制）。
- 均线系统必须**与实际已有走势相吻合**（如下跌段用斐氏参数 5、13、21、34、55、89、144、233），走势未大变即可沿用。

## 九类分类
- 用该系统对所有股票"打横"分类：以本次行情**未曾攻克的最小周期均线**为准，8条均线分成9类，最差者完全在所有均线之下；最厉害的不一定完全在所有均线之上。
- 统计各均线附近聚集的股票数量，可预示大盘的压力位置。

## 轮动操作
- 股票在 N 类调整、要升 N+1 类需折腾较长时间；故一旦某趋势级别走势在 N 类出现顶背驰，可先出来，利用这几天去找已调整充分、可再启动或补涨的股票。
- **缠中说禅板块强弱指标**：把板块内各股类别数平均，均值越大板块越强；最强者为领涨板块，其动态最关键。
- 把所有板块的强弱指标列于一图，轮动次序与节奏一目了然，配合个股走势分析即可做轮动；此分类可用电脑程序实现。
