# 走势类型与走势终完美核心定理

> **关联原文**：[[../../raw/015-教你炒股票15_没有趋势_没有背驰.md|教你炒股票15课]]、[[../../raw/017-教你炒股票17_走势终完美.md|教你炒股票17课]]、[[../../raw/102-教你炒股票102_再说走势必完美.md|教你炒股票102课]]

## 概述

缠论建立在对市场所有可能形态的**完备性分类**基础之上。所有市场走势都可以无遗漏地分解为三种走势类型：**上涨**、**下跌**与**盘整**。

## 走势类型的精确定义

1. **上涨**：在某级别走势中，包含**两个或两个以上同级别走势中枢**，且后一个中枢的最低点 $ZD_2$ 严格高于前一个中枢的最高点 $ZG_1$（即 $ZD_2 > ZG_1$）。
2. **下跌**：在某级别走势中，包含**两个或两个以上同级别走势中枢**，且后一个中枢的最高点 $ZG_2$ 严格低于前一个中枢的最低点 $ZD_1$（即 $ZG_2 < ZD_1$）。
3. **盘整**：在某级别走势中，**只包含一个走势中枢**的走势类型。

## 走势终完美核心定理 (Completeness Theorem)

> **缠中说禅技术分析基本原理一**：任何级别的任何走势类型终要完成。

### 定理内涵
- **结构完成性**：一个走势类型一旦开始，必须完成其最低结构约束（盘整必须至少形成一个中枢，趋势必须至少形成两个中枢并产生背驰）才能宣告终结。
- **连接唯一性**：走势类型的连接只有三种可能：上涨 + 下跌、上涨 + 盘整、下跌 + 上涨、下跌 + 盘整、盘整 + 上涨、盘整 + 下跌。
- **操作指导**：投资者永远不要预测走势何时暴跌或暴涨，只需在当下观察该级别走势类型是否已经“完美”。一个未完美的走势必然延续，已完美的走势必然转折。
