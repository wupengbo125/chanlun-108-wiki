# 第51课：短线股评荐股者的传销把戏

## 荐股传销机制
- 国人赌博心理重，构成群体性癫狂的基础；短线荐股者如传销般利用它。
- 最简模型：在大浏览量媒体随机荐股，只要少量信众次日集中买入（如5000人×2000股＝1000万），就足以把股票撑涨；未买者留下"荐得准"的印象成为下次资源，赚钱者四处忽悠，人群滚动扩大，直到资金流入与筹码松动达到平衡。
- 严密化：设分级会员、交会费、获优先购买权，控制购买流量、逐步扩散，可支撑较长时间，实质演化为多人组织的庄家（无一人挂虚号的监管风险，但稳定性差、树倒猢狲散）。

## 生命演化
- 短线传销最终必使最大量的人被套、外围资源枯竭而崩溃，每日荐 N 股者寿命不长，一轮大调整就消灭一大批；长线、结构精细的系统则逐步演化为私募基金。
- 基金进一步演化为对冲基金或合伙制结构，在赎回与风险忍受上回旋更大、市场生命更高。市场如大海，各种资金形态并存、不会一统天下。

## 猎鲸者
- 作者自况为**猎鲸者**：须对所有猎杀对象有最清楚认识、找最佳攻击点，只对最大的生物（鲸群）感兴趣。
- 曾荐16只（14只加 VC 股600635、北京旅游000802）是为让人专心学习；其后不再点具体股，以免人多变成传销、被人抬轿。
- 说过的会负责到底，但教的是"渔"的方法：关键是有什么级别的买卖点、而不是对象。股票是小道、条条小道通大道，期望有人自我磨练成为猎鲸者、由小道而大道。
