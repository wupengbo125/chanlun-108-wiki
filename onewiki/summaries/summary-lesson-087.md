# 第87课：逗庄家玩的杂史4（做底吃货）

> 源文件：[[../../raw/087-教你炒股票87_逗庄家玩的一些杂史4.md|查看原文]]

## 核心：成本为王
- 吸货无所谓底部：有筹码、有钱、有时间，成本都能摊下来；足以影响走势的分力，各级别的顶底与差价都是自己的。
- 多数庄家做死，是因为没有成本概念、仍是散户心态（见市值上涨就晕）；股票只是抽血凭证，能抽到血才是本事。
- **成本没洗到0就不必大力拉抬**，应来回折腾把成本做到0；真正的拉抬不花钱，若拉抬要花钱，说明价格已高、资金流入跟不上，早该回头砸。最终把筹码做成负成本、翻 N 次方倍后再大甩卖，才最安全。

## 经典做底案例（老鼠仓抢跑）
1. 在强压力位顶住、接走所有解套盘，并不断假突破，逼技术派交出筹码（此时买到的是最高成本）。
2. 借当天必须平仓的透支，早晨把钱连同透支全部买光；下午痛苦地平仓，瀑布砸穿平台，"被套追债"传闻四起。
3. 第二、三天老鼠仓与知情盘蜂拥出逃，所有抛盘在远处被一个无名口袋吸光。
4. 随后强力买盘如熔岩连续扫光、让人买不到；回到原平台又突然停买，沉寂后多杀多、价格却不跌，筹码尽入大口袋。
5. 最后在谁都想不到的时刻，不到15分钟迅速突破上方巨大套牢压力区。
