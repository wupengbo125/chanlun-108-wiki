# 第103课：学屠龙术前先学好防狼术

> 源文件：[[../../raw/103-教你炒股票103_学屠龙术前先学好防狼术.md|查看原文]]

## 防狼术（傻瓜化风控）

- 在没过关防狼术前，不必研究中枢、级别——有了它至少不会在大盘大跌时被严重侵犯。
- 只看最简单的 **MACD**：0轴划分多空主导。一旦 MACD 黄白线陷入 0 轴之下，对应时间周期即进入空头主导，必须远离。
- **回避所有 MACD 黄白线在 0 轴下面的市场或股票，这就是最基本的防狼术。**
- 按自己的能力定一个**最低时间周期**（如60分钟或30分钟）：一旦该周期 MACD 在0轴以下，就彻底离开市场，直到重新站上0轴再说。
- 技术更高者，可在背驰情况下介入（这是最高要求，不做普遍要求）。
