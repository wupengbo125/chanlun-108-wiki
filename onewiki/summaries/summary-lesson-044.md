# 第44课：小级别背驰引发大级别转折

## 情形与机理
- 困难情形是"背驰级别小于当下走势级别"，即小转大。
- 案例：30分钟 `a+A+b+B+c` 中 c 为1分钟背驰。c 至少含一个5分钟中枢（否则 B 无法完成、无三买）；设 c' 为 c 最后5分钟中枢，1分钟顶背驰只在 c' 之后、必拉回 c'，整体围绕 c' 震荡，要出现大的向下变动须 c' 先出第三类卖点。

## 小背驰-大转折定理
- **小级别顶背驰引发大级别向下的必要条件，是该走势最后一个次级别中枢出现第三类卖点；底背驰对应第三类买点。**
- 只有必要条件、没有充分条件：出现三卖并不必然导致大转折、不必然回到 B。故比"背驰级别＝走势级别、必回最后中枢"的一般情况要弱、也更复杂。

## 操作应对
- 30分钟操作下，小背驰必至少导致5分钟向下：若该向下不回到构成三买那5分钟走势的高点（最强时甚至不触其最后5分钟中枢），则在可接受范围、无须理睬；一旦跌破该高点，任何向上回抽都必须先离开。
- 筹码较多时，最后5分钟中枢出三卖先出一部分，跌破上述高点再出清，未跌破可回补、权当短差。
- 不能见1分钟背驰就全走（否则等于按1分钟操作）；能按1分钟操作就不必选30分钟。一定量资金可在1分钟背驰时出部分、据回调再定。底背驰反之。
