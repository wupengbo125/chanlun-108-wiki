# 第37课：背驰的再分辨

> 源文件：[[../../raw/037-教你炒股票37_背驰的再分辨.md|查看原文]]

## 先须是趋势
- **没有趋势，没有背驰**。`a+A+b+B+c` 有背驰，首先它要是趋势，即 A、B 是同级别中枢；若 A 级别大于 B，则整体只是围绕 A 的震荡，不存在背驰，最多盘整背驰。
- 多义性只是多角度：可把 b、c 当成 B 的次级波动，但不能因此忘了整体是趋势。**多义性不是含糊性**，不是怎么分都可以。

## c 与 b 的级别
- **c 必然是次级别**，至少包含对 B 的一个第三类买卖点，否则只是 B 的小级别波动，用盘整背驰处理。
- b 有可能小于次级别（力度最大的是连续缺口），但 b 的级别不能大于 c；若 c 以连续缺口完成，背驰可能性很小，且最弱走势概率极大。
- 上涨中 c 必创新高、下跌中 c 必创新低，否则按围绕 B 的次级别震荡、以盘整背驰判断。

## c 的内部与区间套
- c 含第三类买卖点，则其内部至少含两个次级别中枢（满足次级别离开、回拉不重回中枢），二者构成次级别趋势。
- 可对 c 继续套用 `a+A+b+B+c` 做次级别分析，形成**区间套**，对背驰位置逐级精确定位。
