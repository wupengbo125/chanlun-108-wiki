# 三类买卖点

> 市场中所有的安全盈利机会，完备地归属于三类买卖点，无一漏网。

## 体系概述
在缠论中，任何转折点根据几何形态学与动力学分析，必然且只能归入以下三类买卖点之一：

```mermaid
graph LR
    A["趋势背驰"] --> B["第一类买卖点 (1B/1S)<br/>极值转折点"]
    B --> C["第二类买卖点 (2B/2S)<br/>次级别回抽确认点"]
    C --> D["第三类买卖点 (3B/3S)<br/>中枢破坏加速点"]
    D --> E["新趋势 / 新中枢"]
```

## 三类买卖点分类详解
1. **[[第一类买卖点]] (1B / 1S)**：
   - **成因**：趋势的离开段发生标准趋势 [[背驰与盘整背驰]]；
   - **特点**：左侧转折极值点，利润空间最大，但要求极高的 [[区间套定理]] 识别力。
2. **[[第二类买卖点]] (2B / 2S)**：
   - **成因**：一买/一卖之后，次级别回抽不破前低（或反弹不破前高）；
   - **特点**：右侧确认点，安全性最高，资金容量大，是稳健主力的必争之地。
3. **[[第三类买卖点]] (3B / 3S)**：
   - **成因**：次级别脱离中枢后，次回调不跌回中枢上轨 $ZG$ 之内；
   - **特点**：中枢被彻底破坏，延伸终结，常为主升浪最暴烈的加速风口。

## 买卖点完备性定理
缠中说禅在第 21 课证明：**除这三类买卖点外，在数学公理化意义上不存在第四种合法的买卖点**。任何走势的转折，必然由这三类买卖点相互嵌套与转化构成。
